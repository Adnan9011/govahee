# پیشنهاد نام و دامنه

نام نمایشی محصول hard-code نیست (`PLATFORM_DISPLAY_NAME` / `PLATFORM_DISPLAY_NAME_FA`).  
این فایل فقط **پیشنهاد برند و دامنه** است؛ موجودی nic.ir / رجیسترار را تضمین نمی‌کند. قبل از ثبت، هر نام را در nic.ir و یک Whois بین‌المللی چک کنید.

معماری و نیازمندی: [`README.md`](README.md) · [`README_REQUIRE.md`](README_REQUIRE.md)

---

## معیار انتخاب

دامنهٔ خوب برای این محصول باید:

1. **حاکمیتی به‌نظر نرسد** — پیشوند `gov`، واژهٔ وزارت/ملی/رسمی، و شباهت به CA دولتی ممنوع است.
2. **با رقیب قاطی نشود** — مخصوصاً «گواهی آنلاین».
3. **با SSL / امضای دیجیتال / مودیان قاطی نشود** — کاربر آموزشگاه نباید فکر کند گواهی مالیاتی یا جیکا می‌خرد.
4. کوتاه باشد (QR و `/verify/{token}` روی دامنهٔ کوتاه خواناتر است).
5. به فارسی و انگلیسی قابل تلفظ باشد.
6. برای بازار ایران **`.ir`** بگیرد؛ برای حفاظت برند **`.com` یا `.app`**.

تمایز محصول: فارسی، RTL، شمسی، درگاه ریالی، صدور انبوه، QR، استعلام، PDF.

## الگوی دامنه (بعد از انتخاب برند)

فرض: برند `example`.

| نقش | دامنه |
|-----|--------|
| لندینگ و اعتماد | `example.ir` |
| پنل (SPA) | `app.example.ir` |
| استعلام عمومی / QR | `verify.example.ir` |
| API | `api.example.ir` |
| حفاظت برند | `example.com` یا `example.app` → ریدایرکت به `.ir` |
| وایت‌لیبل بعدی | `certificates.CUSTOMER.com` (هنوز در محصول routing ندارد) |

بستهٔ ثبت پیشنهادی برای هر برند نهایی: **`.ir` + `.com` + `.app`**.

`.ir` برای nic.ir معمولاً شناسه/شرکت ایرانی می‌خواهد. اگر شرکت ثبت نشده، اول `.com`/`.app` را قفل کنید.

`SITE_URL` / `FRONTEND_SITE_URL` باید همان دامنهٔ عمومی استعلام باشد تا QR غلط نسازد.

## سه پیشنهاد اول

### ۱. گواه — Gavah *(پیشنهاد اصلی)*

| | |
|--|--|
| فارسی | گواه |
| دامنه | `gavah.ir` · `gavah.app` · `gavah.com` |
| استعلام | `verify.gavah.ir/{token}` |

**چرا:** «گواه» یعنی شاهد، نه خودِ ورقهٔ «گواهی». با محصول هم‌خوان است: پلتفرم شهادت می‌دهد که *سازمان ثبت‌شده صادر کرده*. املای `Gavah` پیشوند انگلیسی `Gov` ندارد. کوتاه است. از «گواهی آنلاین» فاصله دارد.

**ریسک:** هنوز به ریشهٔ گواهی نزدیک است؛ در تبلیغات باید یک‌بار تمایز گفته شود.

نام نمایشی پیشنهادی: `Gavah` / `گواه`

### ۲. همگواه — Hamgavah

| | |
|--|--|
| فارسی | همگواه |
| دامنه | `hamgavah.ir` · `hamgavah.com` |
| استعلام | `verify.hamgavah.ir/{token}` |

**چرا:** ساخت اختصاصی (هم + گواه). یعنی صادرکننده و سامانه با هم گواهی صدور می‌دهند؛ ادعای اعتبار قانونی محتوا نیست. برای علامت تجاری مناسب‌تر از واژهٔ عام.

**ریسک:** کمی طولانی‌تر از Gavah؛ تلفظ برای غیرفارسی‌زبان سخت‌تر.

نام نمایشی: `Hamgavah` / `همگواه`

### ۳. صدراک — Sadrak

| | |
|--|--|
| فارسی | صدراک |
| دامنه | `sadrak.ir` · `sadrak.app` · `sadrak.com` |
| استعلام | `verify.sadrak.ir/{token}` |

**چرا:** از «صدور» می‌آید (کار اصلی محصول) بدون ادعای «مدرک». برند ساختگی، کوتاه، برای SaaS ایرانی الگوی آشنا (`-ک`). با رقیب و جیکا برخورد معنایی ندارد.

**ریسک:** معنی برای مخاطب جدید باید در لندینگ یک‌خط توضیح داده شود.

نام نمایشی: `Sadrak` / `صدراک`

## اگر فقط یک بسته بخرید

ترتیب خرید (تا اسم آزاد باشد):

1. `gavah.ir` + `gavah.com` + `gavah.app`
2. اگر `gavah` گرفته بود: `hamgavah.ir` + `hamgavah.com`
3. اگر هر دو گرفته بود: `sadrak.ir` + `sadrak.com` + `sadrak.app`

زیردامنه را همان روز در DNS رزرو ذهنی کنید (`app` و `verify`)؛ لازم نیست جدا ثبت شوند.

## نام محصول در تنظیمات

بعد از ثبت دامنه، در `.env` / `PlatformSettings`:

```
PLATFORM_DISPLAY_NAME=Gavah
PLATFORM_DISPLAY_NAME_FA=گواه
SITE_URL=https://verify.gavah.ir
FRONTEND_SITE_URL=https://gavah.ir
```

(مقادیر را با دامنهٔ واقعی عوض کنید.)

شعار پیشنهادی هم‌خوان با اصل حقوقی محصول:

- FA: «صادر کنید، بفرستید، استعلام بگیرید — اعتبار محتوا با صادرکننده است.»
- EN: «Issue, send, verify. We confirm the issuer, not the credential’s legal status.»
